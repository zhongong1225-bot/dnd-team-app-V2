# 编辑器弹窗 UI 设计规范

> 适用于：BUFF编辑器、种族编辑器、背景编辑器、专长编辑器等所有编辑弹窗
> 核心目标：**紧凑、整齐、无滚动**

---

## 一、输入控件宽度规则

### 1.1 宽度由内容决定

- 输入框、下拉菜单、步进器的宽度必须**刚刚够展示内容**
- 禁止使用 `w-full` 或固定大宽度，应根据内容类型设定：
  - 短数值（1-2位）：`w-12` (48px)
  - 中等数值（3-4位）：`w-16` (64px)
  - 长文本（5-10字）：`w-24` (96px)
  - 超长文本：`w-32` (128px) 或 `w-40` (160px)

### 1.2 标签+数值 横排

- 标签和数值输入必须在同一行，禁止换行
- 示例：`移速：[30] 尺` 必须一行展示
- 标签右对齐，数值左对齐，单位紧跟数值

### 1.3 成组数值均分

- 多个相关数值横排时，使用均分网格
- 示例：属性加值 `力量 [+2] 敏捷 [+1] 体质 [+0]` 三等分

---

## 二、排版紧凑规则

### 2.1 单行优先

- 内容项只有一条时，**必须**排成一行
- 禁止不必要的换行（如"移速：30尺"不能分成两行）
- 只有当内容项 ≥2 且类型不同时才考虑换行

### 2.2 均分网格对齐

- 多用 `grid-cols-2`、`grid-cols-3`、`grid-cols-4` 均分布局
- 每个网格项内部居中对齐
- 利用均分营造整齐感，避免参差不齐

### 2.3 间距统一

- 行间距：`gap-2` (8px) 或 `gap-3` (12px)
- 列间距：与行间距保持一致
- 分组间距：`gap-4` (16px) 或 `gap-6` (24px)
- 禁止使用奇数间距（如 `gap-5`、`gap-7`）

---

## 三、字号层级规则

### 3.1 三级字号体系

| 层级 | 用途 | 字号 | 字重 | 颜色 |
|------|------|------|------|------|
| 一级 | 弹窗标题、分区标题 | 16px | 600 | `#e0e0e0` |
| 二级 | 字段标签、选项名 | 14px | 500 | `#c0c0c0` |
| 三级 | 辅助说明、单位 | 12px | 400 | `#8899aa` |

### 3.2 统一应用

- 同一层级的内容必须使用相同字号
- 禁止在同一区域内出现 4 种以上字号
- 数值输入框内文字用 14px，单位用 12px

---

## 四、禁止滚动规则

### 4.1 弹窗高度控制

- 弹窗最大高度：`max-h-[85vh]`
- 内容超出时**必须**精简或分页，禁止出现垂直滚动条
- 如果内容确实很多，考虑分成多个标签页或折叠面板

### 4.2 横向禁止溢出

- 所有容器 `overflow-x: hidden`
- 内容宽度必须 ≤ 容器宽度
- 长文本使用省略号 `text-overflow: ellipsis`

### 4.3 内容精简策略

- 删除冗余说明文字
- 默认折叠高级选项
- 相关字段合并到一行
- 使用图标代替文字（如 ⚡ 代表动作类型）

---

## 五、标签对齐规则

### 5.1 标签右对齐

- 字段标签统一右对齐（`text-right`）
- 数值输入左对齐（`text-left`）
- 形成视觉分隔线，提升可读性

### 5.2 冒号统一

- 标签后加中文冒号 `：`
- 冒号宽度固定，不参与对齐计算

---

## 六、按钮样式规则

### 6.1 主按钮

- 背景：`#c79a42`（金色）
- 文字：`#1a1a1a`（深色）
- 宽度：固定 `w-20` (80px) 或自适应内容
- 高度：`h-8` (32px)

### 6.2 次按钮

- 背景：`#2a3a4e`（深灰蓝）
- 边框：`1px solid #3a4a5e`
- 文字：`#c0c0c0`
- 宽度：与主按钮保持一致

### 6.3 按钮组

- 多个按钮横排时，间距 `gap-2`
- 确认按钮在右，取消按钮在左

---

## 七、分组与分隔规则

### 7.1 分组标题

- 使用一级字号（16px）
- 下方加 `border-b border-gray-700` 分隔线
- 标题与内容间距 `mt-2 mb-3`

### 7.2 卡片式分组

- 相关字段用卡片包裹：`bg-gray-800 rounded-lg p-3`
- 卡片之间间距 `gap-3`
- 卡片内部字段间距 `gap-2`

---

## 八、颜色规范

### 8.1 背景色

- 弹窗背景：`#1e2a3a`
- 输入框背景：`#253345`
- 禁用态背景：`#1a2535`

### 8.2 边框色

- 普通边框：`#3a4a5e`
- 聚焦边框：`#c79a42`（金色）
- 错误边框：`#ef4444`（红色）

### 8.3 文字色

- 主文字：`#e0e0e0`
- 次文字：`#8899aa`
- 禁用文字：`#556677`

---

## 九、特殊控件规则

### 9.1 下拉菜单

- 高度固定 `h-8` (32px)
- 文字居中或左对齐
- 禁止出现横向滚动

### 9.2 步进器

- 按钮宽度 `w-6` (24px)
- 数值显示宽度根据内容自适应
- 整体横排，禁止换行

### 9.3 复选框/单选框

- 标签紧跟控件右侧，间距 `gap-2`
- 多个选项横排时均分宽度
- 选中态使用金色 `#c79a42`

---

## 十、检查清单

设计完成后，逐项检查：

- [ ] 所有输入框宽度是否刚刚够展示内容？
- [ ] 单条内容项是否排成一行？
- [ ] 是否使用了均分网格对齐？
- [ ] 字号是否统一为三级体系？
- [ ] 是否出现任何滚动条？
- [ ] 标签是否右对齐？
- [ ] 间距是否统一（8px/12px/16px）？
- [ ] 按钮样式是否一致？
- [ ] 颜色是否符合规范？
- [ ] 弹窗高度是否 ≤ 85vh？

---

## 十一、禁止案例

### ❌ 禁止：下拉菜单撑满整行

两个分隔符之间的下拉菜单不应撑满全部剩余宽度：

```
| 伤害类型 「                                          下拉菜单                                                        」|
```

问题：
- 下拉菜单被拉伸到行尾，视觉上松散、不紧凑
- 大量空白区域浪费空间
- 不符合"宽度由内容决定"原则

### ✅ 正确：下拉菜单宽度贴合内容

```
| 伤害类型 「  火焰伤害  ▼」                                              |
```

优点：
- 下拉菜单宽度刚好容纳最长选项文字
- 右侧留白自然，整体紧凑
- 多个字段可以并排放在同一行

---

## 十二、反面示例

### ❌ 错误示范

```
移速：
[30] 尺

力量 [+] [-]
[2]
```

问题：
- 标签和数值换行了
- 步进器没有横排
- 间距不统一

### ✅ 正确示范

```
移速：[30] 尺

力量：[-] [2] [+]  敏捷：[-] [1] [+]
```

优点：
- 标签和数值在同一行
- 步进器横排紧凑
- 多个属性均分对齐
