统一网格系统

标准宽度单位 1u = 30px，所有卡片共用同一网格：
类别 (1u=30px) + 来源 (2u=60px) + 特性区 (12u=360px) + BUFF简称 (4u=120px) + 留白 (1fr) + 齿轮 (1u=30px)
左侧内容固定 570px，右侧留白自动填充，齿轮按钮右对齐。内容在列内居中，BUFF 简称左对齐。
卡片固定高度 52px，三组统一。BUFF 简称列预留 3 行容量（每行 12px + 2px 间距），实际显示行数取决于简称字数和 BUFF 条数。

设计要点总结

1. 6 列网格：标准卡 30+60+360+120+1fr+30，窄卡 30+60+270+120+1fr+30，左侧内容固定（标准 570px / 窄卡 480px），中间留白自动填充，齿轮右对齐
2. 固定高度 52px：三组卡片高度完全统一
3. BUFF 简称左对齐：固定 120px 列宽，预留 3 行容量（12px×3 + 2px×2 间距），实际行数取决于简称字数和 BUFF 条数
4. 特性区宽度：标准卡（装备）360px，窄卡（种族/职业/专长）270px，按钮和名称居中显示
5. 名称 + 使用一体按钮：特性名 + ⚡ + 使用，带金色边框，min-width: 200px
6. 装备位下拉：来源列放 <select> 下拉选择装备位
7. 装备能量条按钮：整个按钮就是能量条，背景显示充能进度（满=金色，低=橙色），名称+⚡使用+步进器叠在上面
8. 步进器：− 按钮 + 数值 + 按钮，在能量条内部右侧
9. 消耗信息：放在 title 悬浮提示，不占按钮空间
10. 禁用态：冷却中/资源不足时按钮整体半透明
11. 同调标签可点击：点击切换激活/未激活状态，默认暗色，激活后变亮
