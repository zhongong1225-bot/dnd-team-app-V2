# 编辑卡统一布局规范

> 所有编辑卡（种族、职业、专长、装备）共用同一套 6 列网格系统，固定高度 52px。
> 参考原型：`docs/button-design-preview.html`

---

## 一、网格系统

### 1.1 标准单位

`1u = 30px`（内容宽度），每列额外含左右各 `8px` padding。
列总宽 = 内容宽 + 16px（左右各 8px），使用 `border-box` 模型。

### 1.2 两种网格变体

| 变体 | 适用卡片 | 列定义（含 padding） | 左侧固定总宽 |
|------|---------|---------------------|------------|
| 标准 | 装备卡 | `46px 76px 376px 136px 1fr 76px` | 706px |
| 窄卡 | 种族/职业/专长 | `46px 76px 286px 136px 1fr 46px` | 600px |

### 1.3 六列定义

| 列序 | 名称 | 单位 | 内容宽 | 列总宽(含padding) | 对齐方式 |
|------|------|------|--------|------------------|---------|
| 1 | 同调/类别 | 1u | 30px | 46px | 居中（窄卡竖排文字/装备卡勾选框） |
| 2 | 来源/装备位 | 2u | 60px | 76px | 居中（窄卡两行文字/装备卡下拉） |
| 3 | 特性/物品区 | 9u/12u | 270px/360px | 286px/376px | 内容居中 |
| 4 | BUFF简称 | 4u | 120px | 136px | 标签左对齐 |
| 5 | 留白/数量重量 | 1fr | 弹性 | — | 装备卡右对齐 |
| 6 | 操作区 | 1u/2u | 30px/60px | 46px/76px | 图标居中 |

### 1.4 列分隔线

每列右侧有 `1px solid #2a3a4e` 分隔线（`border-right`），网格 `gap: 0`。

---

## 二、卡片基础

- 固定高度：`52px`
- 背景：`#1e2a3a`
- 边框：`1px solid #2a3a4e`，圆角 `8px`
- 行间距：`margin-bottom: 8px`
- 溢出隐藏：`overflow: hidden`

---

## 三、各列详细规则

### 3.1 第1列：同调/类别

**窄卡（种族/职业/专长）—— 竖排类别标签**

- 竖排文字（`writing-mode: vertical-rl`）
- 字号 12px，字重 600，字距 3px
- 颜色按类别区分：
  - 种族：`#6ba3d6`（蓝）
  - 职业：`#c79a42`（金）
  - 专长：`#a78bfa`（紫）
  - 同调：`#2d6b65`（暗青），激活态 `#4ecdc4`（亮青），可点击切换

**标准卡（装备）—— 同调勾选框**

- 原生 checkbox，居中显示
- 勾选表示物品已同调，参与计算
- 未勾选表示未同调

### 3.2 第2列：来源/装备位

**窄卡 —— 来源信息（两行文字）**

- **必须使用 flex column 布局**，不能用 `<br>` 换行（flex 容器内 `<br>` 无效）
- 两行内容：
  - 主行（`.main`）：字号 9px，颜色 `#8899aa`
  - 副行（`.sub`）：字号 8px，颜色 `#667788`
- 两行均 `white-space: nowrap`，内容居中
- 行间距 `gap: 1px`

```html
<div class="cell source-info">
  <div class="main">人类</div>
  <div class="sub">天生获得</div>
</div>
```

| 卡片类型 | 主行 | 副行 |
|---------|------|------|
| 种族 | 种族名（如"人类"） | 获取方式（如"天生获得"） |
| 职业 | 等级（如"X级获得"） | 子职/来源（如"月亮结社"） |
| 专长 | 等级（如"X级获得"） | 专长名（如"XX专长"） |

**标准卡 —— 装备位下拉**

- 使用原生 `<select>` 元素，支持 `<optgroup>` 分组
- 宽度 100%，高度 28px
- 字号 11px，文字居中
- 适配 60px 内容宽度：`padding: 0 4px`
- 样式：边框 `#3a4a5e`，背景 `#253345`，文字 `#8899aa`

下拉选项（使用 `<optgroup>` 分组）：

```
<optgroup label="手持">
  <option>主手</option>
  <option>副手</option>
</optgroup>
<optgroup label="备用">
  <option>备用1</option>
  <option>备用2</option>
  <option>备用3</option>
</optgroup>
<optgroup label="穿戴">
  <option>身穿</option>
  <option>脚穿</option>
  <option>指戴</option>
  <option>手穿</option>
  <option>脖带</option>
  <option>头带</option>
  <option>外袍</option>
</optgroup>
<option>背包</option>
```

- 选择"背包"时物品回到背包状态（未装备）
- 选择装备位时自动装备到对应位置
- 下拉选项根据物品类型过滤（如盾牌不能选主手）

### 3.3 第3列：特性/物品区

特性区根据是否有主动技能，呈现不同内容：

#### 无主动技能（窄卡）
- 纯文字显示特性名，字号 16px，字重 600

#### 有主动技能（种族/职业/专长）
- **名称 + 使用 一体按钮**（`.feature-ability-btn`）
- 结构：特性名 + ⚡ + "使用"
- 带金色边框按钮，`min-width: 200px`
- 消耗信息放在 `title` 悬浮提示中
- 禁用态（冷却中/资源不足）：整体 `opacity: 0.4`

#### 有主动技能（装备）
- **能量条一体按钮**（`.equip-ability-btn`）
- 整个按钮就是能量条：背景显示充能进度
  - 满充能：金色渐变
  - 低充能（≤20%）：橙色渐变
- 按钮内容叠在能量条上方：名称 + ⚡ + "使用" + 步进器
- 名称自动扩展占满剩余空间（`flex: 1`），超长截断省略号
- 步进器：− 按钮 + 数值（如 "50/50"）+ 按钮
- **充能与护盾池互斥**：同一位置显示充能数或护盾池层数，不会同时出现

#### 选择型特性（二选一）
- 特性名旁显示竖排标签"二选一" + 下拉按钮
- 标签竖排（`writing-mode: vertical-rl`），字号 10px

### 3.4 BUFF简称（第4列）

- 固定 120px 列宽
- 标签左对齐
- 预留 3 行容量（每行 12px 高 + 2px 间距）
- 实际显示行数取决于简称字数和 BUFF 条数
- 标签样式：字号 8px，边框 `#2a3a4e`，背景 `#1a2535`

### 3.5 留白/数量重量（第5列）

**窄卡：纯留白**
- 无内容，`1fr` 自动填充剩余宽度
- 作用：将操作按钮推到右侧

**标准卡（装备）：数量 + 重量（右对齐）**
- `1fr` 弹性宽度 = 容器总宽 - 固定列总和
- 内容靠右排列，左侧自然留白
- 数量步进器：约 65px（`-` 按钮 + 数字 + `+` 按钮）
- 重量：约 45px（如 "3.2 lb"）
- 两者之间间距 8px
- 当物品无数量（quantity=1 且不可叠加）时，只显示重量
- 当物品既无数量也无重量时，此列为空

```
← ──────────── 1fr（动态宽度）──────────── →
┌─────────────────────────────────────────────┐
│  空白    重量(~45px)   [×1] 数量步进器(~65px) │
└─────────────────────────────────────────────┘
```

### 3.6 操作区（第6列）

**窄卡：单齿轮**
- 编辑入口，字号 14px
- 默认颜色 `#556677`，悬浮变金色 `#c79a42`
- 占满整列宽高（46px）

**标准卡（装备）：三齿轮**
- 三个图标：编辑(Pencil) + 存放(Package) + 删除(Trash2)
- 每个图标 14px × 14px，间距 4px
- 总宽：14 × 3 + 4 × 2 = 50px（适配 60px 内容宽度）
- 默认颜色 `#556677`，悬浮变金色 `#c79a42`
- 列宽 2u = 76px

## 四、装备与背包统一

### 4.1 统一物品列表

装备栏和背包栏合并为同一个物品列表，所有物品使用相同的 6 列网格卡片。
通过第2列的装备位下拉菜单控制物品的装备状态。

### 4.2 排序规则

已装备物品按优先级自动排序：

1. 主手（武器/法器）
2. 副手（武器/盾牌/法器）
3. 备用1 → 备用2 → 备用3
4. 身穿 → 脚穿 → 指戴 → 手穿 → 脖带 → 头带 → 外袍
5. 其他穿戴

- 用户通过下拉菜单切换装备位后，卡片自动上移到对应位置
- 背包物品排在最后
- 若无备用位，护甲类自动紧跟手持类之后

### 4.3 视觉分组

- 所有已装备物品外层包一个视觉差异区域（不同背景色或边框），与背包物品区分
- 背包物品在视觉分组下方，使用相同卡片样式

### 4.4 添加物品

- 添加物品按钮放在列表底部
- 新物品默认进入"背包"状态（下拉选"背包"）
- 用户通过下拉菜单切换到装备位即自动装备
- 同调需手动勾选第1列复选框

## 七、注意事项

1. **来源列两行显示**：必须用两个 `<div>`（`.main` + `.sub`）配合 `flex-direction: column`，不能用 `<br>` 换行
2. **装备卡始终用标准网格**：不添加 `narrow` 类
3. **种族/职业/专长用窄卡网格**：添加 `narrow` 类
4. **列宽含 padding**：所有列宽 = 内容宽 + 16px（左右各 8px），使用 `border-box` 模型
5. **BUFF简称列左对齐**：其余列内容居中
6. **消耗信息不占按钮空间**：放在 `title` 属性做悬浮提示
7. **充能与护盾池互斥**：同一物品不会同时有充能和护盾池，共用能量条按钮内的步进器位置
8. **列5弹性宽度**：装备卡列5为 `1fr`，宽度随容器变化，数量/重量始终右对齐
