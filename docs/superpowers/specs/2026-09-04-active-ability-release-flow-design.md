# 主动技能分步释放流程设计

> 日期：2026-09-04
> 状态：待用户审阅

---

## 1. 背景与动机

当前 AbilityUseModal 是一个单步弹窗：打开 → 确认 → 立即执行所有效果（资源消耗、掷骰、结算）。问题：

- **缺乏仪式感**：所有效果瞬间完成，没有"蓄力→释放"的节奏
- **无法中途调整**：法术环位选错、目标选错时已经执行完毕
- **攻击型流程缺失**：D&D 攻击需要"先投攻击骰→问DM→再投伤害"，当前一步到位不符合实际跑团流程
- **资源消耗时机不合理**：确认就扣资源，但玩家可能还想改参数

## 2. 设计目标

1. **所有主动技能统一走多步流程**（攻击、豁免、治疗、变身、召唤、BUFF）
2. **掷骰是不可撤回的仪式时刻** — 掷骰前可随时取消不消耗资源，掷骰瞬间扣资源
3. **3D 骰子动画贯穿所有掷骰步骤** — 保持现有的仪式感
4. **单弹窗 + 内部进度条** — 不弹出多个窗口，步骤在同一个弹窗内切换
5. **攻击型走"投攻击骰→问DM→命中才投伤害"流程**

## 3. 技能类型分类

| 类型 | 判定条件 | 步骤数 |
|------|---------|--------|
| 攻击型 | effects 含 attack roll（d20 + 加值 vs AC） | 4 步 |
| 豁免型 | effects 含 saving throw（DC 判定） | 3 步 |
| 治疗型 | effects 仅含 healing | 3 步 |
| 变身型 | effects 含 creature_transform | 3 步 |
| 召唤型 | effects 含 summon | 3 步 |
| BUFF 型 | effects 仅含 buff/增益效果 | 3 步 |
| 混合型 | 同时含攻击 + 伤害等多阶段 | 4 步（按攻击型走） |

优先级：攻击型 > 豁免型 > 其他。只要 effects 里有攻击骰，就走 4 步攻击流程。

## 4. 流程详细设计

### 4.1 攻击型（4 步）

```
步骤 1：准备
  - 选择法术环位（如有法术位消耗）
  - 选择充能数量（如有多档位）
  - 显示资源消耗预览
  - 按钮：[取消] [下一步]

步骤 2：确认
  - 显示攻击加值预览（d20 + 加值）
  - 显示伤害骰预览（如 2d6 + 3）
  - 显示附加效果描述
  - 按钮：[取消] [投攻击骰]

步骤 3：投攻击骰 ← 不可撤回点
  - 触发 3D 骰子动画（d20）
  - 显示结果：自然骰值 + 加值 = 总攻击值
  - 资源在此刻消耗
  - 按钮：[未命中] [命中，投伤害]
  - 点"未命中" → 直接跳到结果页（无伤害）
  - 点"命中，投伤害" → 进入步骤 4

步骤 4：投伤害骰 → 结果
  - 触发 3D 骰子动画（伤害骰）
  - 显示伤害明细（各骰子点数 + 加值）
  - 如果是重击，显示额外骰子
  - 按钮：[关闭]
```

### 4.2 豁免型（3 步）

```
步骤 1：准备
  - 选择法术环位
  - 显示资源消耗预览
  - 按钮：[取消] [下一步]

步骤 2：确认
  - 显示豁免 DC
  - 显示伤害骰预览
  - 显示附加效果描述
  - 按钮：[取消] [投伤害骰]

步骤 3：投伤害骰 → 结果 ← 不可撤回点
  - 触发 3D 骰子动画
  - 显示 DC 和伤害明细
  - 资源在此刻消耗
  - 按钮：[关闭]
```

### 4.3 治疗 / 变身 / 召唤 / BUFF（3 步）

```
步骤 1：准备
  - 选择环位 / 选择生物（变身/召唤）/ 选择数量
  - 显示资源消耗预览
  - 按钮：[取消] [下一步]

步骤 2：确认
  - 预览效果（治疗量、变身目标、召唤生物等）
  - 按钮：[取消] [执行]

步骤 3：执行 → 结果 ← 不可撤回点
  - 如有骰子（如治疗骰），触发 3D 骰子动画
  - 如无骰子（如纯 BUFF），显示执行动画/特效
  - 资源在此刻消耗
  - 显示结果明细
  - 按钮：[关闭]
```

## 5. 进度条设计

弹窗顶部固定显示进度条，贯穿所有步骤：

```
  ① ——— ② ——— ③ ——— ④
 准备    确认    掷骰    结果
```

视觉规范：
- **已完成步骤**：金色圆点 + 金色连线（#c79a42）
- **当前步骤**：金色圆点 + 微发光效果
- **未完成步骤**：灰色圆点 + 灰色连线（#34455f）
- 圆点直径 28px，内含步骤编号，连线高度 3px

3 步流程隐藏第 4 个节点（自适应宽度）。

## 6. 资源消耗时机

| 步骤 | 可取消？ | 资源状态 |
|------|---------|---------|
| 准备（步骤 1） | 可以，关闭弹窗 | 不消耗 |
| 确认（步骤 2） | 可以，关闭弹窗 | 不消耗 |
| 掷骰（步骤 3） | 不可取消 | **立即消耗** |
| 结果（步骤 4） | 关闭弹窗 | 已消耗 |

资源消耗发生在步骤 3 开始的瞬间，与 3D 骰子动画同步触发。这意味着：
- 法术位消耗在骰子飞出时扣除
- 充能次数在骰子飞出时扣除
- 如果步骤 3 是"投攻击骰"且玩家选择"未命中"，资源已消耗但无伤害

## 7. 攻击型"问 DM"交互

步骤 3 投完攻击骰后，弹窗停留在攻击结果页面，显示两个按钮：

- **未命中**：直接跳转到结果页，显示"攻击未命中"，关闭弹窗
- **命中，投伤害**：进入步骤 4，投伤害骰

这个设计符合线下跑团流程：玩家投骰 → 告诉 DM 总数 → DM 判断是否命中 → 玩家投伤害。

## 8. 3D 骰子动画集成

所有掷骰步骤必须触发 `dnd-external-roll` 自定义事件：

```
window.dispatchEvent(new CustomEvent('dnd-external-roll', {
  detail: {
    animate: true,
    formula: diceFormula,      // 如 "1d20", "2d6+3"
    diceValues: diceValues     // 每颗骰子的点数数组
  }
}))
```

关键约束：
- 攻击骰：先投 d20，动画完成后显示结果
- 伤害骰：投伤害骰组，动画完成后显示明细
- 重击：在伤害骰组中加入额外骰子
- 无骰子效果（纯 BUFF）：不触发骰子动画，用 CSS 过渡动画代替

## 9. 状态机设计

用显式的 `step` 变量替代当前的布尔标志组合：

```
step: 'prepare' | 'confirm' | 'roll_attack' | 'roll_damage' | 'result'
```

状态转移：

```
prepare → confirm        （点"下一步"）
prepare → closed         （点"取消"）
confirm → roll_attack    （点"投攻击骰"，攻击型）
confirm → roll_damage    （点"投伤害骰"，豁免型）
confirm → result         （点"执行"，无骰子型）
confirm → closed         （点"取消"）
roll_attack → roll_damage  （点"命中，投伤害"）
roll_attack → result       （点"未命中"）
roll_damage → result     （动画完成后自动）
```

回退规则：
- prepare 和 confirm 之间可以自由来回
- 进入 roll_* 后不可回退
- 任何步骤都可以关闭弹窗（roll_* 步骤关闭 = 放弃但资源已消耗）

## 11. 边界情况

### 11.1 无骰子效果
纯 BUFF 效果（如增益、变身）在步骤 3 不投骰子，直接显示执行结果。步骤 3 的"掷骰"标签改为"执行"。资源仍在进入步骤 3 时消耗。

### 11.2 多效果组合
一个技能同时含攻击 + 治疗 + BUFF：按攻击型走 4 步流程，治疗/BUFF 效果在步骤 4 一起结算显示。

### 11.3 法术位消耗
- 固定消耗：步骤 1 自动显示将消耗的环位，不可更改
- 自由消耗：步骤 1 提供环位下拉选择

### 11.4 资源不足
在步骤 1 检查资源，不足时禁用"下一步"按钮并显示原因（与当前行为一致）。

### 11.5 攻击型选"未命中"后的资源
资源已消耗，不退回。这符合 D&D 规则：你确实尝试了攻击，只是没打中。法术位/充能不会因为攻击未命中而恢复。

### 11.6 召唤/变身的生物选择
生物选择放在步骤 1（准备），步骤 2 确认时显示已选生物的预览。

## 12. UI 视觉规范

### 弹窗尺寸
- 宽度：保持当前 max-w-lg（约 512px）
- 高度：自适应内容，最小 320px

### 进度条
- 位于弹窗内容顶部，距上边缘 16px
- 圆点：28px 直径，金色（#c79a42）或灰色（#34455f）
- 连线：3px 高，颜色跟随两端状态
- 步骤标签：10px 字号，位于圆点下方 6px

### 步骤内容区
- 距进度条 24px
- 每个步骤内容用淡入动画（opacity 0→1，200ms）
- 按钮区固定在底部

### 按钮样式
- 主按钮（投骰/执行）：金色背景（#c79a42），深色文字
- 次按钮（取消/返回）：透明背景，灰色边框
- 危险操作（未命中）：暗红色背景（rgba(230,57,70,0.2)），红色文字

### 不可撤回提示
进入步骤 3 时，顶部进度条下方短暂显示红色提示条："资源已消耗，无法撤回"（2 秒后淡出）。
