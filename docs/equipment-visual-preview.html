本页是装备栏的 1:1 复刻副本，只用于视觉优化评审，不影响线上代码。
上半 = 现状（行高 52 / 徽章 24 / 现状图标 / 现状配色）；下半 = 加高方案（行高 60 / 徽章 32 / 精致图标 / 收敛配色）。
收敛配色：护甲改蓝（与武器同族）、宝石并入紫（与法器同族）、工具并入金（与容器同族），整列表只剩 蓝/紫/金/绿 四主色。

二、加高方案（行高 60px）

变化点：行高 52→60（按钮 36→44，上下留白各 4px 不变）；徽章 24→32、图标 14→18、衬底 44→52；
颜色遮罩上下缩进 4→6px 适配更高按钮；主动名字 maxWidth 108→100、被动内容左 padding 34→42 给更大徽章让位。

三、图标对照：现状 vs 精致版（32px 徽章实尺寸）

精致版做法：描边 1.5→1.25、圆头圆角、并给每个图标加 1–3 条内部细节线（剑的血槽与护手、盾的中脊与上缘、法杖的水晶与星点、钱袋的束口褶皱、宝石的台面线）。
